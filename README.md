# آواهاب ایونتس — فاز صفر نسخه ۲

وب‌سایت رسمی آواهاب ایونتس — پلتفرم رویداد، پروموشن و مخاطبان دیجیتال.

نسخه ۲ = بازطراحی کامل مطابق کانسپت‌برد: هیروی سینمایی با لوگوی طلایی سه‌بعدی شناور، کارت‌های انیمیشنی تعاملی، ساختار چندصفحه‌ای با سئوی مستقل برای هر صفحه.

## ساختار صفحات

| مسیر | توضیح |
|---|---|
| `/` | خانه: هیرو با لوگوی سه‌بعدی + آمار متحرک + خدمات + رویدادهای پیش رو + CTA |
| `/services` | مرور ۶ خدمت + مسیر همکاری |
| `/services/[slug]` | ۶ صفحه اختصاصی خدمت (سئو + FAQ + Structured Data) |
| `/events` | رویدادها با جستجو و فیلتر دسته‌بندی + بج تاریخ شمسی |
| `/portfolio` | نمونه‌کارها (آماده میزبانی عکس‌های واقعی از پنل ادمین) |
| `/journal` | مجله (آماده انتشار مقالات از پنل ادمین) |
| `/about` | داستان برند + آمار واقعی + روند ۴ مرحله‌ای |
| `/contact` | اطلاعات تماس + فرم مشاوره (ارسال با واتساپ) |
| `/sitemap.xml` | نقشه سایت خودکار (۱۳ آدرس) |

## اجرا

```bash
bun install
bun run dev
```

## آپلود در GitHub (قدم‌به‌قدم)

1. وارد github.com شوید → دکمه **New repository**
2. نام: `avahub-events` → حالت **Private** → **Create repository**
3. روی لینک **uploading an existing file** کلیک کنید (یا بالای صفحه: Add file → Upload files)
4. **محتویات داخل پوشه zip** را (نه خود zip) به‌صورت drag & drop بکشید داخل صفحه
5. صبر کنید فایل‌ها لیست شوند → پایین صفحه: **Commit changes**
6. ریپو آماده است ✅

## اتصال به Vercel

1. وارد vercel.com شوید → **Add New… → Project**
2. ریپوی `avahub-events` را **Import** کنید
3. بدون تغییر تنظیمات → **Deploy** (حدود ۱ دقیقه)
4. لینک زنده می‌شود — تا تأیید شما، دامنه avahubevents.com دست‌نخورده می‌ماند

## فازهای بعدی (نقشه راه)

- فاز ۱: دیتابیس Supabase (رویدادها، ثبت‌نام‌ها، مخاطبان)
- فاز ۲: ورود با گوگل/ایمیل + ارسال ایمیل (Resend)
- فاز ۳: پنل ادمین قوی (داشبورد + مدیریت رویداد + مدیریت رسانه)
- فاز ۴: تجربه عمومی (ثبت حضور + تأیید ایمیل + لیست انتظار)
- فاز ۵: QR Pass + چک‌این + آنالیتیکس UTM
- فاز ۶: محتوا و سئوی عمیق (نمونه‌کار واقعی، مجله، ناحیه کاربری)
- فاز ۷: جلای نهایی + اتصال دامنه avahubevents.com

## نکات فنی

- Next.js 16 + TypeScript + Tailwind CSS 4 + Framer Motion
- فونت: Vazirmatn (قابل تعویض به IRANSansX با تغییر یک متغیر CSS)
- RTL کامل فارسی + Reduced Motion support
- انیمیشن‌ها: پارالاکس ماوس، کارت‌های tilt سه‌بعدی، شمارنده آمار، ترنزیشن صفحه، ذرات محیطی
- تصاویر سه‌بعدی خدمات و لوگوی هیرو: پس‌زمینه شفاف (alpha PNG)
