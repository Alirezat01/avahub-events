بخش ۲ — این بچ چی اضافه کرد؟
─────────────────────────────────────────────
۱) ItemList Schema صفحه رویدادها — فهرست رویدادها برای گوگل
۲) Breadcrumb Schema صفحات ایونت و مقالات مجله
۳) noindex صفحه Login (با layout جدید — گوگل دیگر ایندکسش نمی‌کند)
۴) robots.txt جدید: مسیرهای /admin و /api و /account و /pass
   از خزش گوگل خارج شدند
۵) sitemap: ایونت‌ها حالا lastModified واقعی دارند (تاریخ آخرین ویرایش)
۶) بخش متن «چرا آواهاب» در صفحه اصلی — ۳ پاراگراف سئوشده +
   ۴ کارت ویژگی + لینک داخلی به رویدادها و خدمات
۷) «خدمات مرتبط آواهاب» پایین هر مقاله مجله — هوشمند بر اساس
   تگ و عنوان مقاله، ۲ خدمت مرتبط + لینک همه خدمات
۸) ۶ آیکون خدمات ۷۳٪ سبک‌تر شدند (۴MB → ۱.۱MB) — بدون افت کیفیت
۹) صفحه نمونه‌کارها: پاراگراف معرفی + باکس پایانی با دکمه
   «شروع پروژه بعدی شما» (لینک به تماس) و «مشاهده خدمات»

─────────────────────────────────────────────
بخش ۳ — تست بعد از بیلد سبز (اختیاری ولی خوبه)
─────────────────────────────────────────────
۱) صفحه اصلی را باز کن → پایین، بخش «از ایده تا اجرا» دیده می‌شود؟
۲) صفحه رویدادها → View Source → جستجو: ItemList → باید باشد
۳) یک رویداد → جستجو: BreadcrumbList → باید باشد
۴) صفحه login → View Source → جستجو: noindex → باید باشد
۵) آیکون‌ها در صفحه خدمات هنوز درست نمایش داده می‌شوند؟ (کیفیت)
